# _Logus_

_Logus_ é uma empresa fictícia de consultoria, criada por estudantes de Ciência da Computação e Design do 2º período da turma de 2026.1 da CESAR School.

## Objetivo
Nosso papel é alavancar a sua empresa, criando estratégias baseadas em dados para potencializar seu alcance e retenção de clientes.
